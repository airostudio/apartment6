API Key Configuration

Stripe API keys are set as environment variables on the server — they are never stored in the browser. To update your keys, edit them in your hosting dashboard and redeploy.

Secret Key (server only)

Used by the API to create payment intents and process charges. Never expose this in the browser.

STRIPE_SECRET_KEY=sk_live_…
Publishable Key (browser-safe)

Used in the guest checkout page to initialise Stripe Elements. Safe to include in front-end code.

STRIPE_PUBLISHABLE_KEY=pk_live_…
Where to find your keys: Log in to dashboard.stripe.com/apikeys. Use live keys for production and test keys (prefix sk_test_ / pk_test_) while developing.
